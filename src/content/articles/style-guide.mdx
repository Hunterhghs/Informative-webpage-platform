The opening paragraph gets a drop cap automatically, and the final paragraph ends with the orange end mark. Use `##` headings for sections: they build the contents list shown on wide screens.

## Bar chart

```mdx
<BarChart title="..." subtitle="..." unit="%" source="..."
  highlight={['B']}
  data={[{ label: 'A', value: 12 }, { label: 'B', value: 30 }]} />
```

<BarChart
  title="Bars sort largest-first by default"
  subtitle="Use highlight to pick out one or more bars; negative values are supported"
  unit="%"
  highlight={['Beta']}
  data={[
    { label: 'Alpha', value: 12.5 },
    { label: 'Beta', value: 30 },
    { label: 'Gamma', value: -8 },
    { label: 'Delta', value: 21 },
  ]}
  source="Example data"
/>

## Line and column charts

```mdx
<LineChart title="..." x={[2020, 2021, 2022]}
  series={[{ name: 'A', values: [1, 2, 3] }, { name: 'B', values: [2, null, 4], dashed: true }]} />
```

<LineChart
  title="Lines"
  subtitle="Use null for gaps; add dashed: true for projections"
  unit="%"
  x={[2018, 2019, 2020, 2021, 2022, 2023, 2024, 2025]}
  series={[
    { name: 'Series A', values: [2.1, 2.4, -1.2, 3.8, 3.1, 2.6, 2.4, 2.2] },
    { name: 'Series B', values: [1.2, 1.4, -4.5, 2.9, 2.0, 1.1, null, 1.5] },
  ]}
  source="Example data"
/>

<LineChart
  kind="column"
  wide

    { name: '2025', values: [14, 18, 16, 21] },

## Images

Put image files in `public/images/` and reference them with the Figure component:

```mdx
<Figure src="/images/my-map.png" alt="Describe the image" title="Title" source="Source" />
```

That is everything. Delete nothing here; it never ships.

[^1]: Footnotes collect at the bottom of the article.
